Formnaro AI and local automation
================================

Use Settings > AI / API to configure the optional chat provider or enable
the local interface for another application. These paths are independent.
CAD modelling and the local connection require no cloud account. Sending
chat messages through an online provider can transmit the task's context
and attachments and may incur provider charges.

Review proposed geometry and checks in the preview. Apply to confirm
the change in one Undo step. When requirements or references are missing,
inspect the assumptions before applying. Keep access tokens and provider
credentials out of models, chats and shared files.

Connect a local client
----------------------

Start Formnaro, enable its local interface and copy the connection path
shown in Settings. The default Windows profile is %APPDATA%/offlinecad.
Use Python 3.10 or newer. Run the following from the program directory:

    python ai/offlinecad_ai.py --connection "<connection path>" --mcp --profile compact

From a repository checkout, the canonical script is scripts/offlinecad_ai.py.
The adapter reads the local token internally and connects over loopback.
OfflineCAD command names, paths and identifiers are retained for compatibility.

Read offlinecad_context and offlinecad_scene first. Preview a command batch
with offlinecad_preview against the scene revision. Inspect the preview and
use offlinecad_apply only for a requested change. After a revision conflict,
read the current scene before computing another preview. Preserve existing
sources, parameters, locks and unrelated parts.

The adapter uses MCP revision 2026-07-28 over stdio and supports legacy
handshake clients. The r36 release tag contains the older adapter.

Reference files
---------------

OfflineCAD-KI-Kontext.json describes the shared modelling contract.
OfflineCAD-KI-OpenAPI.json describes the local HTTP interface.
mcp-config-example.json provides a client configuration example.
FORMNARO-MODELLIERFREIRAUM.json describes how to handle unspecified
dimensions and design details. python/examples contains SDK examples.
