# Formnaro Mini für Android

Dieses Verzeichnis enthält die Weboberfläche für die Android-App, die
Gradle-App und die Tests für gemeinsame Modellfunktionen.

Den öffentlichen Android-Pilot und die APK gibt es im
[Android-Repository](https://github.com/andyy909/Formnaro-Android).
Den lokalen Quellbuild beschreibt die [Android-Anleitung](ANDROID.md).
