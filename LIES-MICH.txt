Formnaro | Quick start

1. Extract the complete Windows ZIP to a folder.
2. Open Formnaro.exe (or the included Formnaro start shortcut).
3. Keep the runtime files and resources with the executable.
4. Start a new project, or open an existing .ocad or .fnpack file.
5. Use Save As to save a separate copy before editing an existing project.

The portable package includes the required runtimes. Modelling works offline.
Offline dictation may need a one-time language model download. Cloud AI is
optional and uses the provider you select in Settings.

Nightly r10 adds local-first STL conversion and symmetry reconstruction.
See docs/STL-TO-CAD.md for conversion and docs/USER-GUIDE.md for general use.
Public downloads and release notes:
https://github.com/andyy909/Formnaro-cad/releases

Kurzstart auf Deutsch

Windows-ZIP vollständig entpacken, Formnaro.exe starten und die Laufzeitdateien
bei der EXE belassen. Ein neues Projekt anlegen oder eine vorhandene .ocad- bzw.
.fnpack-Datei öffnen. Mit Speichern unter lässt sich vor der Bearbeitung eine
eigene Kopie anlegen. Die Modellierung funktioniert offline.

Die frühere Versionschronik steht im Repository unter
docs/archive/LIES-MICH-HISTORISCH.txt.

STL-Konverter und Symmetrie werden in docs/GEMEINSAMER-KONVERTER.md erklärt.
