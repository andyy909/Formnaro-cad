Stable 0.150.0-r2 26 Nov 2026

Sketch dimensions and shared agent chat

When you move a sketch element, Formnaro displays the X and Y offsets in millimetres. You can edit them after releasing the pointer. Circles and rectangles have editable size dimensions. You can send a sketch from the tablet to a selected face on the PC and continue editing it there.

With Formnaro CAD 0.4.0 for Android, you can continue the same agent conversation on both devices. To pair the tablet, open “Projekte → Tablet verbinden” in Windows and enable agent chat sharing.

Nightly 0.148.0-r5

Tablet companion mode and direct part transfer

Formnaro creates the TLS certificate for tablet pairing on Windows without a separate OpenSSL installation. Direct part transfer from tablet to PC was tested in an emulator with an Android test build.

Extract the entire Windows x64 ZIP and open “Formnaro starten”. FreeCAD and the STL converter are included. This Nightly is unsigned.

Preview 0.145.0-r1 20 Nov 2026

From Formnaro straight to OrcaSlicer

Edit the model in Formnaro, slice it with Orca, and continue the same AI chat in the slicer. The agent can set layer height, walls, infill, and supports, and report print time and filament estimates. Start the print in Orca.
